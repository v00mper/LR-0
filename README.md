# Лабораторная работа № 0

## Вариант № 2 — «Отскок одного символа»



Консольная программа на Python: символ `*` движется по экрану

и отражается от четырёх границ области движения.



## Описание задачи



Реализовать движение одного символа в консоли с отражением от стен,

управлением скоростью и сбросом положения в центр.

При столкновении с углом символ должен отражаться от обеих стен.



## Возможности программы



- Движение символа по диагонали.

- Отражение от горизонтальных и вертикальных границ.

- Четыре уровня скорости: 1x, 2x, 3x и 4x.

- Возврат символа в центр.

- Обработка изменения размера консоли.

- Восстановление содержимого консоли и положения курсора при выходе.



## Среда выполнения



- Операционная система: Windows.

- Язык: Python.

- Версия Python, использованная при разработке: 3.14.10.

- Запуск: командная строка Windows — cmd.



Используются только встроенные модули Python:

`ctypes`, `msvcrt`, `shutil`, `sys`, `time`.



Устанавливать сторонние библиотеки не требуется.



## Управление



Клавиши работают без нажатия Enter.



- `+` или `=` - увеличить скорость, максимум 4x.

- `-` - уменьшить скорость, минимум 1x.

- Пробел - вернуть символ в центр и установить скорость 1x.

- `q` или `Q` - завершить программу в английской раскладке.

- `Ctrl+C` - завершить программу.



После завершения программа восстанавливает исходный экран консоли

без дополнительных сообщений.
